Counted exactly with a "broken-profile" dynamic program that sweeps the grid once, tracking which cells still have a dangling connection — no route is ever built and thrown away, so it stays fast even when there are trillions of them. Browsing by number works the same way, in reverse: it can reconstruct the exact k-th solution directly, without generating the ones before it. Cross-checked against brute-force enumeration and against OEIS A096969 / A003763.

How the count grows

Every route on a plain N×N grid (no cuts), N = 2 to 10. The y-axis is logarithmic — each gridline is 100× more routes than the one below it.
